# UUa

8ビットSBCからUART経由で小画面のGUIと入力を利用するための、状態保持型UI/VDPの実験プロジェクトです。

## 目的

6502/Z80級のSBCをアプリケーションの主体とし、UI/VDPを表示・入力を担当するI/Oコプロセッサとして利用します。SBCが文書やアプリケーション状態の論理的正本を保持し、VDPがUIオブジェクト、描画、入力処理を担当します。

- 初期ターゲット：コード編集・画像/マップ編集・実行を備える小型統合IDE
- 次のターゲット：マシンモニタ／デバッガ
- 通信：双方向UART（115200bps級でPoCを実施）
- 論理表示：320×240、8×8文字グリッド
- 専用ハードウェア候補：RP2350、HSTXによるDVI出力

## 検証の進め方

まずPC版でUIオブジェクトモデル、DSL/IR、イベント往復、UART条件下の通信量を検証します。その後、実8ビットSBCとRP2350版VDPで同じ上位プロトコルを動かすことを目指します。
