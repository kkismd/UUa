# 共通適合検証データ

PC参照実装とPico 2ファームウェアで、将来同じ上位契約を検証するための共有仕様・テスト入力・期待結果を置く入口です。

## このディレクトリの責務

- 採用済みの共通契約に基づく適合検証データを、必要になった段階で管理する。
- PC固有・Pico 2固有のテスト実行コードやツールチェーンをここへ集約せず、各実装側で管理する。
- 共通検証データの変更時に必要な検証を実行するCI条件は、後続のImpl #13で整備する。

## 現在の状態

この段階では配置方針のみが決まっています。プロトコル、GUI DSL、UI IR、オブジェクトID、fixture形式、ファイル命名規則および期待結果の表現は未決定です。仮のデータ形式やダミーfixtureは作成しません。
